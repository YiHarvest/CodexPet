# BubuYier Codex Pet

This repository contains a Codex v2 custom pet package.

## Install

On Windows, run:

```powershell
.\install.ps1
```

The script copies `bubuyier-ref` into:

```text
%USERPROFILE%\.codex\pets\bubuyier-ref
```

Restart Codex or refresh the pet picker after installing.

## Files

- `bubuyier-ref/pet.json`
- `bubuyier-ref/spritesheet.png`
- `install.ps1`
